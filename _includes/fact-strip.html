{%- comment -%} "Is this reusable for us?" — the at-a-glance strip at the top of an entry page. Renders every field whose effective card slot is `icon` (the signal fields), plus any `card: meta` field that has not already been shown in the page header. Values carry their `option_meta` icon, `description` (as a tooltip) and `warn` tone. Facts with no value are skipped; the whole strip disappears when nothing is left. Usage: {% include fact-strip.html fields=ent_fields entry=page shown=ent_shown %} fields schema.fields entry the entry page object shown optional "|key|key|" string of field keys already rendered elsewhere Local assigns are prefixed `fs_` so nothing leaks into the caller's scope. {%- endcomment -%} {%- assign fs_fields = include.fields -%} {%- assign fs_entry = include.entry -%} {%- assign fs_shown = include.shown | default: '' -%} {%- assign fs_icon_fields = fs_fields | card_fields: 'icon' -%} {%- assign fs_meta_fields = fs_fields | card_fields: 'meta' -%} {%- assign fs_candidates = fs_icon_fields | concat: fs_meta_fields -%} {%- capture fs_items -%} {%- for fs_f in fs_candidates -%} {%- assign fs_key = '|' | append: fs_f.key | append: '|' -%} {%- if fs_shown contains fs_key -%}{%- continue -%}{%- endif -%} {%- assign fs_values = fs_entry[fs_f.key] | as_list -%} {%- if fs_values.size == 0 -%}{%- continue -%}{%- endif -%}
