{%- comment -%} Entry image, resolved honestly — no generated placeholder. Usage: {% include entry-thumb.html entry=page img_class="rounded-md" %} Params: entry (required, an entry page object), img_class (extra classes on the ). Fallback order: explicit `thumbnail` front matter -> the first image of the first `images`-type schema field -> `thumb.jpg` when it exists on disk -> NOTHING. Callers MUST treat empty output as "this entry has no picture" and omit the media band entirely (capture the include and check for blank), per design-brief principle 5.
